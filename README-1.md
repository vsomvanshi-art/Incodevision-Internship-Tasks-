# Incodevision Internship — Python Tasks

This folder contains two beginner-friendly console applications.

## Files
- `task1_password_generator.py` — generates a random password using Python's `secrets` module.
- `task2_todo_list.py` — lets the user add, view, complete, and delete tasks.
- `VIDEO_RECORDING_GUIDE.md` — a simple plan for recording your real VS Code demo.

## Requirements
- Python 3.8 or newer
- Visual Studio Code
- Python extension for VS Code (Microsoft)

No extra Python packages are required.

## Run Task 1
1. Open this folder in VS Code.
2. Open `task1_password_generator.py`.
3. Choose **Terminal → New Terminal**.
4. Run:
   ```bash
   python task1_password_generator.py
   ```
   If that command does not work on Windows, try:
   ```bash
   py task1_password_generator.py
   ```
5. Enter a password length of at least 4, such as `12`.

## Run Task 2
In the VS Code terminal, run:
```bash
python task2_todo_list.py
```
On Windows, you can also try:
```bash
py task2_todo_list.py
```
Try adding two tasks, viewing them, completing one, deleting one, and exiting.

## Important
The To-Do List keeps tasks in memory while the program is running. They reset after you exit. This is fine for a simple console-based task; file saving can be added later if your internship asks for it.
