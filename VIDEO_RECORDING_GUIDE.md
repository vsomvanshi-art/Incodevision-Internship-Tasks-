# VS Code Demo Video Recording Guide

Record the actual program running on your computer. This keeps the demo authentic and proves that the code works.

## Before recording
1. Open the project folder in Visual Studio Code.
2. Close unrelated tabs and notifications.
3. Increase the editor/terminal font size so the text is readable.
4. Test both scripts once before recording.
5. Use Windows Snipping Tool screen recording, Xbox Game Bar (`Win + Alt + R`), or another screen recorder available on your computer.

## Suggested 2–3 minute video plan

### Opening (5–10 seconds)
Show the project folder and say:
"Hello, this is my Incodevision internship task demonstration. I have completed two Python console applications: Password Generator and To-Do List App."

### Task 1 — Password Generator (35–50 seconds)
1. Open `task1_password_generator.py` and briefly show the code.
2. Open the terminal and run `python task1_password_generator.py` (or `py task1_password_generator.py`).
3. Enter `12` when asked for the password length.
4. Show the generated password.
5. Say: "This program uses Python's secrets module to generate a random password containing lowercase letters, uppercase letters, numbers, and symbols."

Do not show or use a real password that protects one of your accounts.

### Task 2 — To-Do List App (60–90 seconds)
1. Open `task2_todo_list.py` and briefly show the menu code.
2. Run `python task2_todo_list.py` (or `py task2_todo_list.py`).
3. Enter `1`, then add `Complete internship task`.
4. Enter `1` again, then add `Prepare project report`.
5. Enter `2` to view all tasks.
6. Enter `3`, then `1` to mark the first task completed.
7. Enter `4`, then `2` to delete the second task (if it is still listed as task 2).
8. Enter `2` to show the final list, then `5` to exit.

### Closing (5–10 seconds)
Say:
"These tasks helped me practise Python functions, loops, conditions, lists, user input, and the secrets module. Thank you."

## Export and submission
- Save the recording as MP4 if your recorder offers that option.
- Watch the video once to confirm the text is readable and both programs run correctly.
- Upload the source `.py` files to GitHub, as your internship instructions request.
- Create a LinkedIn post and tag `#incodevision` if required.
- Submit the completed tasks using the official submission form provided by the internship.

## Recording tip
A screen recording must be captured from your own VS Code session. This guide provides the sequence and narration; it is not a pre-recorded video.
